# XPS Constrained Fitting Workbench

一个完全在浏览器本地运行的 XPS 物理约束拟合工具。无需上传实验数据到服务器，也无需安装桌面程序。

## 功能

- 导入 `.txt`、`.csv`、`.xy`、`.dat` 两列谱图
- 结合能统一校准
- Shirley、Tougaard U3、线性和无背景
- GL(30)、GL(50)、GL(70) 与非对称金属峰
- Ir 4f、Pb 4f、O 1s 模板
- 峰位、FWHM、面积及上下限约束
- 自旋轨道双峰固定分裂、面积比和组内同宽
- 实验谱、总拟合、背景、组分谱与残差
- R²、Reduced χ²、RMSE 和残差偏置
- CSV、JSON、SVG 结果导出

## 使用

直接打开 `index.html`，或启动本地静态服务器：

```bash
python -m http.server 8080
```

浏览器访问 `http://127.0.0.1:8080/`。

也可以点击“载入 Ir 4f 演示谱”体验完整流程。

## 数据格式

第一列为结合能（eV），第二列为强度。允许空格、制表符、逗号或分号分隔，能量升序和降序均可。

```text
58.00  102.3
58.05  101.9
58.10  103.1
```

## 科学使用边界

本工具强调物理约束，但不会自动证明化学态归属。高 R² 不等于化学解释正确。新增峰应同时满足原始谱肩峰或系统性残差、合理峰宽以及独立的化学证据。O 1s 归属尤其应结合其他核能级、APXPS 工况趋势、DFT core-level shift、XAS 或 Raman。

浏览器版使用确定性的边界坐标优化，适合交互式预拟合、统一约束和结果导出。正式发表前建议与 CasaXPS、Avantage 或其他经过验证的软件交叉检查，并完整报告校准、背景、峰型和约束。
